# Eco Health

Sistema de gestão para cuidados de idosos.

## Funcionalidades

- Cadastro de idosos
- Cadastro de medicamentos
- Cadastro de tarefas
- Alertas automáticos
- Dashboard de gestão

## Tecnologias

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

Projeto desenvolvido para a disciplina de Projeto Integrador.
